# M23. Ловец кристаллов

## Питч
Тёмное поле, под слоем пыли спрятаны кристаллы. Игрок водит лупой по области и, обнаружив кристалл, удерживает лупу над ним несколько секунд, пока камешек не соберётся. Пыль [X] маскируется под кристалл — если её изучить полностью, придётся начинать сначала.

## Фантазия
Спелеолог в пещере с фонариком-лупой: свет вырывает из мрака блеск кристалла, но пыльные комки обманывают глаз.

## Цель этапа
Собрать все 3 кристалла и не «изучить» до конца пыльный ложный объект.

## Управление
- ЛКМ + перетаскивание по тёмной зоне — лупа следует за курсором.
- Тап и перетаскивание — на мобильных.
- Стрелки / WASD — точное позиционирование лупы клавиатурой.

## Основные правила
- Кристалл виден только пока попадает в радиус лупы (65 px).
- Пока лупа неподвижно висит над кристаллом — заполняется кольцо-таймер удержания.
- Удержание сбрасывается, как только лупа сходит с объекта.
- Пыль [X] под лупой выглядит подозрительно, а не как кристалл (красный тон).

## Объекты
- Лупа с индикатором прогресса удержания.
- Тёмная рабочая зона.
- 3 скрытых кристалла.
- 1 ложный пыльный объект [X].

## Этапы
| Этап | Время удержания | Лимит времени этапа | Правила пыли [X] |
|------|-------------------|----------------------|-----------------|
| 1    | 2.0 c             | без лимита           | только предупреждение |
| 2    | 1.5 c             | 60 c                 | полное изучение — сброс |
| 3    | 1.2 c             | 45 c                 | полное изучение — сброс |

## Условия провала (сброс этапа)
- Пыль [X] изучена до конца на этапах 2–3.
- Истекло время этапа (2 и 3).

## Тексты интерфейса
- «Перемещайте лупу по области, находите скрытые кристаллы и удерживайте 2 сек для сбора!» — базовая инструкция.
- «Изучение кристалла… Удержание: t / T сек» — прогресс.
- «Подозрительный объект [X]… Удержание: t / T сек» — при удержании пыли.
- «Изучена пыль [X]! Этап сброшен.» — провал на 2–3 этапе.

## Крайние случаи
- Собранные кристаллы исчезают и не отвлекают на повторный сбор.
- При провале или переходе этапа лупа возвращается в центр, все объекты снова скрыты.
