# KBPro Analytics Builder

## Purpose

Подключить аналитические события к модулю/экрану KBPro: старт/финал модуля, ключевые действия игрока, результаты — через сервис статистики/аналитики проекта (`LazySrv`), с ключами событий через `Constants`. Покрывает задачи вида `[Dev][логика] … - события аналитики` и события модулей.

## When To Use

* Задача «Аналитика - события» / «залогируй события модуля X».
* Нужно отследить прохождение/действия/результаты мини-игры или экрана.

## Do Not Use

* Для сохранения игрового прогресса/состояния (это SaveService, не аналитика) — разве что задача прямо об этом.
* Для настройки внешней аналитической панели/дашборда.

## Core Rules

1. **Доступ через LazySrv** к сервису статистики/аналитики; `.Dispose()` в `Dispose()` модуля.
2. **Ключи событий — через Constants**, без хардкод-строк. См. [analytics-contract.md](file://references/analytics-contract.md).
3. **Точки lifecycle:** старт модуля (`Startable`), завершение (`OnComplete`), ключевые действия — в соответствующих местах флоу; без дублей.
4. **Точный API сервиса сверить в исходнике** (напр. `IStatisticService`) — не выдумывать сигнатуры.
5. **Минимум данных** — только то, что заказано; никаких персональных/лишних полей.

## Workflow

1. По ТЗ/таблице событий определи список событий и их ключи/параметры.
2. Найди в проекте сервис аналитики/статистики и его API (`rg` по `IStatisticService`/`Analytics`/`SetValue`).
3. Заведи ключи в `Constants` (или зафиксируй для заведения пользователем).
4. Встрой вызовы в нужные точки lifecycle/флоу через `LazySrv<...>`.
5. Освободи сервис в `Dispose`; проверь отсутствие дублей.

## Output Format

* Изменённые системы/модуль с вызовами аналитики + список ключей `Constants`.
* Таблица «событие → точка вызова → параметры».

## Test Prompts

1. «Залогируй старт и завершение модуля Кариес + событие на каждый просверленный зуб.»
2. «Свяжи задачу `Аналитика - события` доп.экранов: открытие главного экрана, выбор пациента, переход в диагностику.»
3. «Проверь, что ключи событий вынесены в Constants и сервис освобождается в Dispose.»
