# Пример входного ТЗ (фрагмент)

Это пример раздела ТЗ, который скилл `bitrix-task-json-builder` превращает в
[sample-backlog.json](sample-backlog.json). Обрати внимание: шаги уже заданы пунктами
ТЗ (4.1–4.4) — скилл берёт их 1:1, а не выдумывает своё разбиение.

---

## 4. Строительство дома

Модуль отвечает за пошаговое возведение дома игроком на выбранном участке.

**4.1 Фундамент.** Игрок выбирает площадку, после чего запускается заливка фундамента с прогресс-баром. По завершении фундамент фиксируется и открывается возможность возведения стен.

**4.2 Возведение стен.** На готовом фундаменте игрок устанавливает стеновые панели. Стены ставятся по периметру; пока не установлены все панели, крыша недоступна.

**4.3 Монтаж крыши.** После завершения стен игрок монтирует кровлю. Анимация установки крыши сопровождается визуальным эффектом завершения этапа.

**4.4 Внутренняя отделка.** Игрок расставляет предметы интерьера из доступного набора. Завершение отделки помечает дом как достроенный и начисляет награду.
