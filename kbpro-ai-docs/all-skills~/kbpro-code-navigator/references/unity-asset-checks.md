# Проверка Unity ассетов — Справочник навигатора

Перед изменением или созданием Unity-ассетов (сцен, префабов, ScriptableObjects, материалов, шейдеров) проведите следующие проверки для сохранения целостности проекта.

## 1. Проверка префабов (Prefabs)
* **Префаб-источник (Prefab Source) против экземпляра (Instance)**: Изменения структуры, слоев и ссылок должны производиться строго на оригинальном ассете префаба (в режиме редактирования префаба), а не на его экземпляре на сцене.
* **Связи префабов (Prefab Variants / Nested Prefabs)**: Проверьте, является ли префаб вариантом другого префаба. Внесение изменений в родительский префаб повлияет на все его варианты.
* **Отсутствующие скрипты (Missing Scripts)**: В инспекторе префаба не должно быть серых блоков с надписью `Missing (Mono Script)`.

## 2. Проверка сцен (Scenes)
* **Иерархия сцены**: Изучите структуру GameObject на сцене. Проверьте основные узлы: камеры, источники света, UI Root, игровые контроллеры.
* **Теги и Слои (Tags & Layers)**: Сверьте, на каких слоях расположены физические объекты и коллайдеры. Проверьте матрицу коллизий в настройках проекта, чтобы убедиться в правильности пересечения физических слоев.

## 3. Проверка ScriptableObjects (Конфигурации)
* Разделяйте ассеты настроек (конфигов) и динамическое состояние игры. ScriptableObjects должны использоваться только для хранения статичных данных (шаблоны, параметры баланса, ссылки на префабы).
* Изменение ScriptableObjects во время игры (Play Mode) перезаписывает файл на диске. Не используйте их как хранилища runtime-состояния.

## 4. Материалы, Шейдеры и Рендеринг (URP)
* Проверьте, какой шейдер назначен на материал (например, Shader Graph шейдер проекта или стандартный Lit).
* Обратите внимание на URP-свойства материалов: прозрачность (Transparency Queue), параметры свечения (Emission) и поддержку SRP Batcher.
* Перед редактированием Shader Graph ассетов изучите руководство `unity-shader-ai-guidelines.md`.

## 5. Ресурсы Addressables
* Проверьте, принадлежит ли префаб или ассет к группе Addressables.
* Сверьте имя ключа Addressable с константами загрузки.
* Не используйте классическую синхронную загрузку `Resources.Load` для Addressables-объектов.
