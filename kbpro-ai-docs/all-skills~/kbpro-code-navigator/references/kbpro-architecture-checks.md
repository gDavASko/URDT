# Архитектурные проверки KBPro — Справочник навигатора

При анализе кода проекта в процессе навигации всегда сверяйте структуру классов со следующими фундаментальными стандартами архитектуры KBPro:

## 1. Разделение ответственности и SOLID
* **Вью-слой (`GameComponent`)**: Изучите компоненты. Убедитесь, что они содержат только ссылки на компоненты Unity (анимации, рендереры, TMPro) и методы их визуального обновления. В них не должно быть никакой бизнес-логики.
* **Логический слой (`LogicSystem`)**: Логические системы не должны наследоваться от MonoBehaviour. Проверьте, что вычисления и управление состояниями происходят здесь.

## 2. Жизненный цикл (Initialize / Dispose)
* Проверьте наличие обязательных вызовов `base.Initialize()` в начале метода `Initialize()` систем/модулей.
* Проверьте вызовы `base.Dispose()` в самом конце метода `Dispose()`.
* Проверьте, что в методе `Dispose()` полностью освобождаются ресурсы (отписка от шины событий, очистка `CompositeDisposable`, отмена `CancellationTokenSource`, освобождение ленивых сервисов `LazySrv`).

## 3. Внедрение зависимостей (Dependency Injection)
* Убедитесь, что системы внедряют зависимости через атрибуты инъекции:
  * `[InjectComponent]` для получения вью-компонентов.
  * `[InjectSystems]` (или метод `Construct()`) для межсистемных связей.
* Проверьте использование глобальных сервисов через обертку ленивого разрешения `LazySrv<T>` (например, `LazySrv<IStatisticService>`). Использование синглтонов вида `Instance.DoSomething()` запрещено.

## 4. Шина событий (EventBus)
* Поиск событий и подписок:
  * Подписки: `EventBus<T>.Register(OnEventCallback)`.
  * Отписка в Dispose: `EventBus<T>.Unregister(OnEventCallback)`.
  * Вызов события: `EventBus<T>.Raise(new T())`.
* Убедитесь, что тип события `T` заведен в структурах контракта модуля и не содержит тяжелых данных.

## 5. UI MVP Стек
Если задача касается экранов, проверьте наследование:
* Презентер: наследует `UIPBase` или `UIPWindow`.
* Вью: наследует `UIVBase` или `UIVWindow`.
* Параметры показа: реализуют интерфейс `IUIShowParams`.
* Убедитесь, что для вывода текстов не используется `UnityEngine.UI.Text` (всегда `TextMeshPro`).
