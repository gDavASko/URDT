# KB Maintenance Pattern

## Use When

The user explicitly requests a change to existing KBPro knowledge-base content, rules, or documentation.

## Process

1. Identify the source-of-truth document and the exact requested correction.
2. Keep the change narrowly scoped and preserve managed-block and repository rules.
3. Run the required KB validation after the change.
4. Report modified documents and validation output.

## Completion

Finish only when the requested documentation change and its validation are complete.
