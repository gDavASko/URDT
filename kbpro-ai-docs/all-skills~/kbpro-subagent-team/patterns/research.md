# Research Pattern

## Use When

The task needs a recommendation, an approach comparison, or unresolved facts before implementation.

## Process

1. Define the research question, decision criteria, and scope.
2. Assign a researcher only if the investigation can be bounded independently.
3. Prefer local primary sources; use external sources only when needed and authorized.
4. Separate facts, inferences, alternatives, risks, and recommendation.

## Completion

Return an evidence-backed recommendation and clearly identify what remains unknown.
