# KB Search Pattern

## Use When

The task needs facts, architecture guidance, or existing patterns from the KBPro knowledge base.

## Process

1. Use the project knowledge-base query workflow with a precise query.
2. Read only the retrieved context that matches the task.
3. If the KB does not answer the question, use targeted local search and record the gap for later documentation work.

## Completion

Use the retrieved evidence in the task result; do not modify the KB in this pattern.
