# Development Pattern

## Use When

The user explicitly authorizes implementation or a code/configuration change.

## Process

1. Identify the affected local code, architecture rules, and acceptance criteria.
2. Research an unclear implementation detail before changing it.
3. Delegate only mechanical, bounded work to a worker; preserve review separation.
4. Implement the minimum scoped change and run relevant machine validation.
5. Assign a judge for independent review when the change is material or risky.

## Completion

Report changed files, validation evidence, and unresolved limitations.
