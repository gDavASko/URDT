# Information Search Pattern

## Use When

The task requires a factual answer but does not modify the knowledge base.

## Process

1. Formulate a narrow query and identify the likely local source.
2. Search locally first; use web sources only when necessary for current or missing information.
3. Read only the matching source sections and record direct evidence.
4. Distinguish confirmed facts from inference.

## Completion

Return the answer with relevant sources and any uncertainty.
