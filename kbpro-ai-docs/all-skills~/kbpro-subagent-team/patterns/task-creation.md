# Task Creation Pattern

## Use When

The user requests a task, task decomposition, backlog item, or work-item creation.

## Process

1. Extract the goal, owner, scope, constraints, dependencies, and done criteria.
2. Split work only into independently verifiable deliverables.
3. Keep creation in draft/read-plan mode unless the user explicitly authorizes external writes.
4. Apply repository-specific task formatting and human gates before creating external items.

## Completion

Return the proposed or created work items with scope, dependencies, and acceptance criteria.
