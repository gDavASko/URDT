Bitrix24: статистика задач команды

📖 Как читать этот отчёт
  1. Источник — задачи Bitrix24, а не git: здесь видно то, чего git не видит (дедлайны, возвраты с проверки, оценки времени), и НЕ видно содержания кода. Полная картина — вместе с git-отчётом perf-audit.
  2. Пары «скорость ↔ качество»: закрытые задачи/мес читаются только вместе с долей возвратов (reopen); цикл задачи — вместе с ней же. Ускорение при росте возвратов — не улучшение.
  3. Dev-задачи отфильтрованы по конвенции команды: тег «Dev» или Dev в названии. Остальные задачи участвуют только в профиле типов.
  4. Возврат (reopen) — задача, вернувшаяся из «на проверке/завершена» обратно в работу. Главный сигнал качества в этих данных.
  5. Все объёмы — за месяц; сравнения только «сам с собой до/после»; таблица людей — не рейтинг, «Внимание» — темы для 1:1.
  6. Флаги: PARTIAL_FIELD_* — поле заполнено не во всех задачах; BUG_RULE_HEURISTIC_UNCONFIRMED — баги определены эвристикой без подтверждения; EXCLUDED_ABSENCE — окно отпуска исключено.
