# Инструкция по генерации отчета для дейлика (Standup Reporter)

Этот скилл предназначен для формирования сухого, фактологического статуса по всей проделанной работе за последние сутки (или за выходные, если сегодня понедельник). Твоя цель — сгенерировать текст, который пользователь сможет просто зачитать на "дейли-скраме".

## 1. Сбор данных
1. Обязательно запусти этот powershell-скрипт сбора данных:
   `C:\Users\DavASko\.gemini\config\skills\davasko-standup-reporter\scripts\scan-workspaces.ps1`
2. Скрипт сам рассчитает период (с 14:00 мск прошлого рабочего дня до текущего момента) и найдет все коммиты и незакоммиченные файлы пользователя во всех проектах компании (в `e:\UnityProjects\IRI`).
3. Дождись завершения работы скрипта и внимательно изучи его вывод.

## 2. Формирование отчета
На основе полученного вывода от скрипта, сгенерируй отчет для стендапа.

**Строгие стилистические правила отчета:**
- **НИКАКИХ ЭПИТЕТОВ И ОЦЕНОК:** Категорически запрещено использовать слова вроде "мощный", "с нуля", "существенно доработал", "навел порядок", "глобальный", "эпичный". 
- **ТОЛЬКО ФАКТЫ:** Пиши сухо, в формате "daily scrum". Используй глаголы действия: "Написал...", "Пофиксил...", "Обновил...", "Вынес...".
- **БЕЗ ТЕХНИЧЕСКОГО МУСОРА:** Не перечисляй пути к файлам и конкретные технические ассеты (вроде `.asset` или `.meta`), если они не несут продуктовой ценности. Например, вместо `MixerEntityConfig.asset` пиши "Пофиксил настройки аудио (микшеры)", вместо `Roboto-Bold SDF.asset` пиши "Пересобрал шрифты TMP".
- **ГРУППИРОВКА:** Группируй работу не строго по мелким репозиториям, а по логическим блокам задач (например: "Инфраструктура/База знаний", "Core", "Игровые проекты").
- **СТАТУС:** Указывай статус: что уже влито (закоммичено), а что висит локально (в процессе).

**Пример идеального отчета (на который нужно ориентироваться):**
```markdown
Всем привет. Мой статус с пятницы и за выходные (или "за вчерашний день", в зависимости от дня недели):

**По инфраструктуре и базе знаний:**
- Написал скрипты для работы с Гантом в Битриксе (выгрузка задач, связи).
- Доработал сбор метрик производительности.
- Часть залил, часть скриптов сейчас доделываю локально.

**По Корове:**
- Пофиксил настройки аудио: отключил автонормализацию. Это уже влито в дев.

**По остальным проектам:**
- Актуализировал локально проекты, сейчас там висят пачки рабочих правок по Addressables и шрифтам.
```

## 3. Вывод
Выведи получившийся отчет пользователю в markdown. Не задавай лишних вопросов и не пиши вводных предложений. Просто выдай готовый текст.
