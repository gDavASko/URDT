# Source Reading Checklist — что и в каком порядке читать (анти-галлюцинация)

> Reference пишется **по фактам из кода**, а не по догадкам. Сначала прочитай источники, потом заполняй секции. Любое непонятное место → `[НЕИЗВЕСТНО — уточнить]`, не выдумывай.

## Что прочитать (в порядке)

1. **`[ModuleName]Module.cs`** → метаданные, lifecycle (3.9), скелет модуля (3.10), внешние сервисы (3.4), EventBus (3.5), способ завершения, Constants (3bis).
2. **Все `*System.cs` (LogicSystem)** → системы (3.3), `[InjectComponent]`-инъекции (3.8), флоу (секция 2), скелеты систем (3.10), переиспользуемые примитивы (3bis).
3. **Все `*Component.cs` (GameComponent)** → компоненты (3.2), `Action`-события, публичные методы (3.10).
4. **SO-конфиг(и) / `*Config.cs`** → ПОЛНЫЙ список полей конфигурации (3.6).
5. **Prefab** (через .prefab/иерархию или builder) → структура (3.7), карта провайдеров (3.8: какой объект в каком `LinkedComponentProvider`).
6. **SOGameModuleSettings / Constants** → module id, transitions, gameWindowId (3bis, как запускается).

## Какой раздел из какого источника заполняется

| Раздел reference | Источник факта |
|------------------|----------------|
| Метаданные, тип завершения | `*Module.cs` |
| 1 Plain Language | ТЗ + поведение из кода |
| 2 Флоу (+flowchart) | `*FlowSystem.cs` / `*Module.cs` |
| 3.1–3.5 структура | все классы модуля |
| 3.6 конфиг | SO/`*Config.cs` (ВСЕ поля) |
| 3.7 префаб | .prefab / builder |
| 3.8 карта инъекций | `[InjectComponent]` в системах ↔ `_componentProviders` в префабе |
| 3.9 порядок base.* | `*Module.cs` (и системы) |
| 3.10 скелет классов | объявления Module/System/Component |
| 3bis контракт | Constants + `*Module.cs` + SOGameModuleSettings |
| 4 sequence | взаимодействие классов из кода |
| 6 заметки/антипаттерны | реальные находки в коде (с обоснованием) |
| 7 Adaptation Guide | синтез: что обобщается на класс задач |

## Дисциплина
- Имена классов/методов/Constants — **скопированы из кода**, не перефразированы.
- Если метод примитива неизвестен — пометь и сверь по `kbpro-primitives-glossary.md` / исходнику, не придумывай сигнатуру.
- Перед сохранением — пройди «Правило 6» из `HowToDescribeModule.md`, включая **reproduction test**.
