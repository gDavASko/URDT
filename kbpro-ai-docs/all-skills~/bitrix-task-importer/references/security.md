# Security Guardrails — Bitrix Import

> Источник: Регламент безопасности импорта задач Bitrix24 KBPro.

## Вебхук — это секрет

- Базовый URL вебхука берётся **только** из переменной окружения `KBPRO_BITRIX24_WEBHOOK_BASE`.
- **Никогда** не хардкодить URL вебхука в скриптах, JSON, логах или коммитах.
- Скрипт обязан падать с понятной ошибкой, если переменная не задана (не подставлять значение по умолчанию).

### Как задать локально (PowerShell, текущая сессия)
```powershell
# <портал> — например company.bitrix24.ru; далее идёт путь входящего вебхука вида /rest/<user_id>/<token>
$env:KBPRO_BITRIX24_WEBHOOK_BASE = "https://<портал>/<путь_входящего_вебхука>"
```
Для постоянного хранения — пользовательская переменная окружения Windows, не репозиторий.

## Ротация

Если вебхук когда-либо был закоммичен, залогирован или передан — **ротировать** его в Bitrix24 (создать новый, отозвать старый) **до** запуска импорта против реального воркспейса, затем задать новое значение локально.

## Прочее

- Не печатать полный URL вебхука в выводе/логах импорта.
- Импорт создаёт реальные задачи у реальных людей — это исходящее действие; перед запуском подтверждать с пользователем количество задач, `GROUP_ID` и `RESPONSIBLE_ID`.
