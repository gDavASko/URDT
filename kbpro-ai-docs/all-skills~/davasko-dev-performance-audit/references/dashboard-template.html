Аудит эффекта нововведений

📖 Как читать этот отчёт (начните отсюда)
  1. Начните со сводной таблицы по людям: колонка «Вердикт» — итог по каждому, «Внимание» — метрики, где динамика человека заметно отличается от группы. Это повод для разговора 1:1, а не оценка.
  2. Пары «скорость ↔ качество» читаются только вместе. Рост скорости при росте доли переделок — не улучшение. Каждая карточка показывает пару целиком.
  3. Все объёмные метрики нормированы «за месяц» — фазы разной длины сравнимы честно.
  4. Сравнения только «сам с собой»: дельты считаются между фазами одного человека. Таблица людей не является рейтингом.
  5. Качественные метрики (LLM-оценки 0–10) даны полосами [min–max] с уверенностью: ✓ высокая, ⚠ средняя, × низкая. Тренд признаётся только если полосы фаз НЕ пересекаются.
  6. Флаги ограничений: ADOPTION_BY_DATE_ONLY — применение нововведения определено только по датам (грубо); LOW_SAMPLE — мало данных, LLM-оценок нет; EXCLUDED_ABSENCE — окно отпуска исключено; UNVALIDATED — оценки ещё не проверены независимым судьёй.
  7. Чего из этого отчёта выводить НЕЛЬЗЯ: зарплатные/кадровые решения, сравнение «кто лучше», оценку сложности задач между людьми. Git видит только следы работы, не её содержание.
