# Жизненный цикл (Lifecycle Flow) и Пауза в AbstractGameModule

Этот справочник описывает стандарты управления жизненным циклом и обработки состояний приостановки (ISuspendable) в оркестраторах `AbstractGameModule`.

---

## 1. Фазы жизненного цикла оркестратора

Оркестратор модуля является центральной точкой входа. Он управляет запуском логических систем и переключением UI.

```
Initialize() → Startable() → [Геймплей] → OnComplete() → Dispose()
```

### 1.1 Метод `Initialize()`
Вызывается при загрузке модуля на сцену.
- **Задача**: Получить ссылки на системы через `GetSystem<T>()`, настроить коллбеки и выполнить подписки на глобальные шины `EventBus`.
- **Порядок base**: Метод `base.Initialize()` должен вызываться строго **последним**! Он активирует механизм внедрения компонентов `[InjectComponent]` в системы.

### 1.2 Метод `Startable()`
Вызывается, когда сцена полностью готова к показу (завершена загрузка, скрыт экран загрузки).
- **Задача**: Включить HUD модуля, воспроизвести фоновую музыку, запустить таймеры.
- **Порядок base**: Метод `base.Startable()` должен вызываться строго **первым**! Он запускает методы `Start()` на всех логических системах модуля.

### 1.3 Метод `OnComplete()`
Вызывается логическими системами при достижении условий победы или завершения.
- **Задача**: Скрыть HUD модуля, записать выходные параметры, подготовить сцену к выгрузке.
- **Порядок base**: Метод `base.OnComplete()` должен вызываться строго **последним**!

### 1.4 Метод `Dispose()`
Вызывается фреймворком при выгрузке модуля и смене сцены.
- **Задача**: Отписаться от всех шин событий, освободить LazySrv.
- **Порядок base**: Метод `base.Dispose()` должен вызываться строго **последним**! Он очистит системы и уничтожит игровой объект модуля.

---

## 2. Поддержка приостановки (ISuspendable)

Если во время работы модуля происходит глобальное событие (например, игрок открыл меню паузы, запустился обучающий диалог), модуль должен быть безопасно приостановлен.

Для этого оркестратор модуля реализует интерфейс `ISuspendable`:

```csharp
using KBP.CORE;
using UnityEngine;

namespace KBP.DENTISTRY_COW.EXAMPLE
{
    public sealed class ExampleModule : AbstractGameModule, ISuspendable
    {
        public bool IsSuspended { get; private set; }

        public void Suspend(bool hide)
        {
            IsSuspended = true;

            if (hide)
            {
                gameObject.SetActive(false);
            }

            // Передаем сигнал приостановки во все системы
            foreach (var system in GetSystems<ISuspendable>())
            {
                system.Suspend();
            }
        }

        public void Resume()
        {
            IsSuspended = false;
            gameObject.SetActive(true);

            // Передаем сигнал возобновления во все системы
            foreach (var system in GetSystems<ISuspendable>())
            {
                system.Resume();
            }
        }
    }
}
```
> [!NOTE]
> Приостановка гарантирует, что таймеры не будут тикать, физические тела остановятся, а пользовательский ввод будет временно заблокирован во время активной паузы.
