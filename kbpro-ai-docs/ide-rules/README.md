# IDE Rules — Мастер-копия настроек ИИ-ассистентов

Каталог `ide-rules/` — это мейнтейнерский центр правил ИИ-ассистентов.

## 📌 ЕДИНСТВЕННЫЙ ИСТОЧНИК ПРАВДЫ: `AGENTS.md`

`AGENTS.md` является **ЕДИНСТВЕННЫМ И ЕДИНЫМ ИСТОЧНИКОМ ПРАВДЫ** для всех правил ИИ во всех проектах и IDE.

Любые прочие файлы настроек для различных IDE и агентов:
- `.cursorrules`
- `GEMINI.md`
- `.windsurfrules`
- `.clinerules`
- `CLAUDE.md`

**КАТЕГОРИЧЕСКИ НЕ ДОЛЖНЫ** создавать дублирующиеся копии текста правил. Все они генерируются скриптом `sync-ai-rules.js` как легкие однострочные отсылки на единый главный файл:

```markdown
Please follow the core agent rules defined in: [AGENTS.md](AGENTS.md)
```

## Структура

```
ide-rules/
├── AGENTS.md                   ← ЕДИНСТВЕННЫЙ ИСТОЧНИК ПРАВДЫ ДЛЯ ВСЕХ ПРАВИЛ
├── copilot-instructions.md     ← Инструкции для GitHub Copilot
├── mcp_config.json             ← Безопасный проектный MCP-шаблон
└── README.md                   ← Этот файл
```

## Как обновить правила

1. Редактируйте **только** `AGENTS.md` (или передайте прямые указания пользователю).
2. Запустите скрипт синхронизации:
   ```bash
   node system/sync-ai-rules.js
   ```
3. Скрипт автоматически обновит `AGENTS.md` во всех проектах и создаст ссылки для всех IDE.
